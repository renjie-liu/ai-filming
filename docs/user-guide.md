# 使用指南：五步出片

Jellyfish 把一集短剧的制作放在一个页面里：**剧本 → 角色场景 → 分镜 → 视频 → 成片**。
AI 模型无需配置：部署时已自动接入 Seedance，默认文本 / 图片 / 视频模型会显示在「模型管理」页顶部。

## 0. 新建作品
- 在「作品」页点「新建作品」，填作品名，在「画面风格」里选一张风格卡（真人实拍 / 动画 / 艺术三组共 26 种：电影胶片、都市偶像剧、悬疑黑色、古装正剧、仙侠奇幻、赛博科幻、日系二维、国漫 3D、水墨写意、黏土定格、像素复古……），需要的话在「风格补充」里再写一句自己的要求（例如「整体偏青橙色调，多用逆光」），最后选比例（竖屏 9:16 / 横屏 16:9）。
- 风格决定整部作品的画面质感：之后的形象、关键帧、视频乃至 AI 起草的剧本都按它生成；创作页顶部会显示所选风格。想要真人脸不被平台限制，选动画或艺术组。
- 创建后直接进入创作页第 ① 步。删除作品需要二次确认，镜头和生成结果会一起删除。

## ① 剧本
- 把剧本或故事粘贴进输入框（没有剧本可以点「用示例试试」）。
- **没有剧本？** 在上方写一句话想法（例如「孙悟空退休后回花果山开民宿」），选一个目标时长，点「AI 起草剧本」。约 20–60 秒后，剧本会填进输入框，带标题、梗概和分段大纲；格式已经按拆分镜的要求写好（场景、角色外貌、「角色：台词」），改到满意再点「一键拆分镜」。起草只分析文字，不扣生成额度。
- 点「一键拆分镜」。系统依次：拆镜头 → 识别角色、场景与道具 → 自动建档并关联到镜头。
- 约 1–2 分钟，只分析文字，不消耗生成额度。完成后自动进入第 ② 步。
- 已拆过镜的一集会显示「已拆出 N 个镜头」，可以直接去分镜板；改了剧本想重拆，点「重新拆分镜」（会清空现有镜头、关键帧和视频）。

## ② 角色场景
- 这里是从剧本里认出来的人和地方，已经自动关联到对应镜头。每张卡都可以编辑。
- 给主要角色点「生成形象」（约 10–30 秒）；之后的关键帧和视频会把形象图当参考，画面才不会换人。「全部生成形象」会标明要生成几张图。
- 点卡片打开编辑：
  - **形象**：「AI 生成」或「上传自己的图片」（手机照片也行，会自动压到 2K 以内）。上传的图直接作为形象 / 参考图。旁边可以选一次生成 1 / 2 / 4 张，多张会一起出现在「历史候选」里。
  - **历史候选**：每次生成和上传过的图都留着，点任意一张即采用；不满意新的随时切回旧的。
  - **其它视角**（角色）：定下正面形象后点「生成三视图」，会以它为参考派生左侧面与背面；生成视频时一并作为参考，人物转身、侧脸也不换脸。
  - **名称、人物设定**：年龄、外貌、服装、气质写得越具体，形象越稳定。
  - **生成提示词**：点「查看提示词」可以看到 AI 实际用的描述，改好再点「AI 生成」。
  - **出现在哪些镜头**：勾选后，这些镜头生成关键帧 / 视频时会参考它的形象。
  - **删除**：从所有镜头解除关联并删除形象图。
- 「新增」可以手动加角色 / 场景 / 道具（例如剧本里没写出来的配角或关键道具）。
- 其它集建过档的角色、场景也会列在这里，标「本集未用到」，选上镜头就能沿用。
- 本集用到的角色 / 场景 / 道具还有没形象的时候，这一步的主按钮是「全部生成形象」，页面会列出还缺哪些；都有图后主按钮才变成「下一步：分镜板」。仍然可以「跳过，去分镜板」，但没有形象图的角色在关键帧和视频里的长相会随机变化。

## ③ 分镜
- 每个镜头一张卡：序号、标题、景别 / 运镜、画面描述、对白、画面里用到的人和物、时长。
- 点「生成全部关键帧」或单卡「生成关键帧」。没有画面描述时 AI 会先写一段再出图；不满意点「重画」。
- 如果还有角色 / 场景 / 道具没有形象图，分镜板顶部会提醒，「生成全部关键帧」会先把这些形象图补齐、等它们出来再出关键帧（形象图是关键帧的参考，顺序反了人物就会换脸）；着急的话点「不等形象，直接出关键帧」。再次打开作品时，若还有角色没形象，会先停在「角色场景」。
- 点卡片进入编辑：
  - **关键帧**：「保存并生成 / 重画」，或「上传自己的图片」直接当首帧。每次重画的结果都留在「历史候选」里，点一张即可切回。
  - **预演四宫格**：点「生成四宫格」，用一张 2×2 的图按时间顺序演四个动作节拍，先看节奏、构图和人物连续性对不对，只花一张图的费用；不对就改节拍再生成一次。
  - **标题、景别、机位、运镜、时长**（4–30 秒）。景别和运镜会翻成带焦段的镜头语言写进视频提示词。
  - **动作节拍**：每行一个动作；两条以上时按时长平均分配时间码（`[0-3s] …` `[3-6s] …`），让一个镜头按顺序演。
  - **画面描述**：就是关键帧提示词，可「AI 改写」。
  - **画面里会用到**：选角色 / 场景 / 道具，关键帧和视频会参考它们的形象；不选则只按文字。
  - **对白**：增删改台词、选说话人（角色或旁白）。
- 也可以「添加镜头」「删除镜头」。
- **调整顺序**：电脑上直接把镜头卡拖到想要的位置；手机上打开镜头编辑，用「上移 / 下移」。序号会自动重排，关键帧和视频跟着镜头走。

## ④ 视频
- 先看确认单：每个镜头的时长、参考方式，总秒数与预计时间。参考方式自动选：
  - **形象参考 N 张**：镜头里的角色 / 场景有形象图时，把它们和关键帧一起给模型，提示词按 [Image 1]、[Image 2] 点名，人物最不容易换脸。
  - **首帧图 + 描述**：只有关键帧时，用它锁定第一帧构图。
  - **仅文字描述**：什么图都没有。
- 点「调整」可以换参考方式、勾选用哪几张素材（角色的侧面 / 背面视图也在列表里）、查看并修改最终发给模型的提示词；也可以「上传自己的视频」直接当这个镜头的成片（mp4 / mov / webm，大文件走浏览器直传）。
- **配音 / 配乐**：在「调整」里「上传配音 / 配乐」（mp3 / wav / m4a），模型会按它的节奏与情绪生成，台词口型与之对齐；确认单上会标「+ 音频」，不需要时点「移除」。
- **承接上一镜**（确认单上的开关，默认开）：镜头按顺序一个接一个生成，每一镜把上一镜的结尾画面作为参考，光线、场景布置和人物站位会延续下来，剪在一起不跳；确认单下方会显示预计总耗时。代价是不能并发，一集 N 个镜头大约要 N × 1–3 分钟，页面要保持打开。关掉开关则所有镜头同时提交，更快，但相邻镜头可能各拍各的。单个镜头「重试」同样会带上一镜的结尾画面。
- 点「开始生成」才扣费。之后每张卡显示排队 / 生成中 x% / 已完成 / 失败。
- 失败会显示原因（例如内容审核未通过），点「重试」「调整」或「修改描述」后重来，其他镜头不受影响。
- 任一镜头完成即可「查看成片」。

## ⑤ 成片
- 播放器按镜头顺序连播；右侧列表可点选单个镜头。
- **合成预览**：点一下把所有镜头在浏览器里拼成一整集，播放器直接整集连播并显示字幕（对白按镜头时长排布），不用下载就能看整体效果；镜头顺序或视频变了需要重新合成。满意后点「下载整集 mp4」立即下载，不会再拼一次；「逐镜播放」切回逐段播放。
- **合成导出**：把所有镜头拼成一个 mp4 并下载，整个过程在你的浏览器里完成，不上传任何内容。首次使用会下载约 31 MB 的合成内核（之后浏览器缓存）；拼接本身只要几秒，混入了参数不同的上传视频时会自动改为重新编码（较慢）。
- **字幕 .srt**：按镜头时长把每句对白排成字幕文件，和 mp4 一起导入剪辑软件即可；字幕不会烧进视频。
- 「下载全部片段」逐个下载 mp4。
- 「继续创作下一集」会在同一作品下新建一集，角色与场景可以沿用。

## 右侧「导演助手」
- 告诉你当前步骤该做什么，并给出主按钮；手机上折叠为底部操作条。
- 「进行中」列出正在跑的任务；「本集用量」估算本集生成了多少图片和多少秒视频。

## 小贴士
- 图片与视频会消耗 Seedance 账户额度，视频最贵；建议先用一个镜头试一遍再批量生成。拆分镜、改文字、上传图片不扣费。
- **真人实拍风格的注意事项**：Seedance 对「看起来像真人」的参考图有限制。本服务默认用 Seedream 5.0 生成形象图，这类图会被平台按「自家模型产物」放行；关键帧是以形象图为参考的图生图，中近景人脸清晰时仍可能被拒，这时系统会自动去掉被拒的那张图重试一次，并在镜头卡上注明「已自动去掉」。上一镜的结尾画面来自 Seedance 自己的视频，不会被拒。想完全避开，新建作品时选动画或艺术组的风格。
- 当前部署（Vercel Hobby）下单个生成任务需在 5 分钟内完成；超时的任务会一直显示生成中，重新生成即可。上传图片大小限制约 4 MB（页面会自动压缩）。
- 左下角「任务中心」可以看所有任务的状态，并跳回创作页对应步骤。
