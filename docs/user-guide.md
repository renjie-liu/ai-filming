# 使用指南：五步出片

Jellyfish 把一集短剧的制作放在一个页面里：**剧本 → 角色场景 → 分镜 → 视频 → 成片**。
AI 模型无需配置：部署时已自动接入 Seedance，默认文本 / 图片 / 视频模型会显示在「模型管理」页顶部。

## 0. 新建作品
- 在「作品」页点「新建作品」，填作品名，选画面（真人 / 动漫）、题材和比例（竖屏 9:16 / 横屏 16:9）。
- 创建后直接进入创作页第 ① 步。删除作品需要二次确认，镜头和生成结果会一起删除。

## ① 剧本
- 把剧本或故事粘贴进输入框（没有剧本可以点「用示例试试」）。
- 点「一键拆分镜」。系统依次：拆镜头 → 识别角色、场景与道具 → 自动建档并关联到镜头。
- 约 1–2 分钟，只分析文字，不消耗生成额度。完成后自动进入第 ② 步。
- 已拆过镜的一集会显示「已拆出 N 个镜头」，可以直接去分镜板；改了剧本想重拆，点「重新拆分镜」（会清空现有镜头、关键帧和视频）。

## ② 角色场景
- 这里是从剧本里认出来的人和地方，已经自动关联到对应镜头。每张卡都可以编辑。
- 给主要角色点「生成形象」（约 10–30 秒）；之后的关键帧和视频会把形象图当参考，画面才不会换人。「全部生成形象」会标明要生成几张图。
- 点卡片打开编辑：
  - **形象**：「AI 生成」或「上传自己的图片」（手机照片也行，会自动压到 2K 以内）。上传的图直接作为形象 / 参考图。
  - **名称、人物设定**：年龄、外貌、服装、气质写得越具体，形象越稳定。
  - **生成提示词**：点「查看提示词」可以看到 AI 实际用的描述，改好再点「AI 生成」。
  - **出现在哪些镜头**：勾选后，这些镜头生成关键帧 / 视频时会参考它的形象。
  - **删除**：从所有镜头解除关联并删除形象图。
- 「新增」可以手动加角色 / 场景 / 道具（例如剧本里没写出来的配角或关键道具）。
- 其它集建过档的角色、场景也会列在这里，标「本集未用到」，选上镜头就能沿用。
- 可以跳过，直接「下一步：分镜板」。

## ③ 分镜
- 每个镜头一张卡：序号、标题、景别 / 运镜、画面描述、对白、画面里用到的人和物、时长。
- 点「生成全部关键帧」或单卡「生成关键帧」。没有画面描述时 AI 会先写一段再出图；不满意点「重画」。
- 点卡片进入编辑：
  - **关键帧**：「保存并生成 / 重画」，或「上传自己的图片」直接当首帧。
  - **标题、景别、运镜、时长**（4–30 秒）。
  - **画面描述**：就是关键帧提示词，可「AI 改写」。
  - **画面里会用到**：选角色 / 场景 / 道具，关键帧和视频会参考它们的形象；不选则只按文字。
  - **对白**：增删改台词、选说话人（角色或旁白）。
- 也可以「添加镜头」「删除镜头」。

## ④ 视频
- 先看确认单：每个镜头的时长、参考方式（有关键帧 = 首帧图 + 描述，没有 = 仅文字），总秒数与预计时间。
- 点「开始生成」才扣费。之后每张卡显示排队 / 生成中 x% / 已完成 / 失败。
- 失败会显示原因（例如内容审核未通过），点「重试」或「修改描述」后重来，其他镜头不受影响。
- 任一镜头完成即可「查看成片」。

## ⑤ 成片
- 播放器按镜头顺序连播；右侧列表可点选单个镜头。
- 「下载全部片段」逐个下载 mp4；「合成导出」会在后续版本提供。
- 「继续创作下一集」会在同一作品下新建一集，角色与场景可以沿用。

## 右侧「导演助手」
- 告诉你当前步骤该做什么，并给出主按钮；手机上折叠为底部操作条。
- 「进行中」列出正在跑的任务；「本集用量」估算本集生成了多少图片和多少秒视频。

## 小贴士
- 图片与视频会消耗 Seedance 账户额度，视频最贵；建议先用一个镜头试一遍再批量生成。拆分镜、改文字、上传图片不扣费。
- **真人实拍风格的注意事项**：Seedance 不接受「看起来像真人」的参考图（包括 AI 生成的写实人像），带关键帧生成视频会被拒绝并提示原因。这时点「改用文字描述重试」，该镜头会只按文字生成；想保留参考图带来的一致性，可以把作品画面改为「动漫」。
- 当前部署（Vercel Hobby）下单个生成任务需在 5 分钟内完成；超时的任务会一直显示生成中，重新生成即可。上传图片大小限制约 4 MB（页面会自动压缩）。
- 左下角「任务中心」可以看所有任务的状态，并跳回创作页对应步骤。
